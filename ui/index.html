MT5 通信
连接你的 MT5
  1. 在 MT5 菜单打开「文件 → 打开数据文件夹」。
  2. 点击下方按钮，选择刚才的数据文件夹，安装通信 EA。
  3. 刷新导航器，将 TianXingBridge 只挂到一个图表（其他周期不要重复挂通信 EA）。通信名称保持与左侧一致。
  4. 保留原有 SMC 纯指标，开启「向 AI 导出数据」。M5、M15、H1 等各开一个图表，分别挂载指标。返回分析页切换图表，即进入该周期策略。
  5. 连接成功后，在 Skills 页面启用交易模型，返回分析页选择图表。
初次安装为只读。需要执行时，在 EA 参数中打开 InpAllowTrading，并开启 MT5 算法交易。AI 开关关闭时逐笔确认；开启后可直接新建限价挂单。
模型密钥由 Windows 本机加密保存；不发送给 EA。
